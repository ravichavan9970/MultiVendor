===============================================================
MULTI-VENDOR ENTERPRISE PLATFORM - RUN COMMANDS & ACCESS INFO
===============================================================

---------------------------------------------------------------
1. SEPARATE PORTALS & DISTINCT RUN COMMANDS
---------------------------------------------------------------

A) BACKEND REST API SERVER (Terminal 1)
   File:     backend/pom.xml & src/
   Command:  npm run backend
             (or .\start-backend.bat)
             (or cd backend && mvn spring-boot:run)
   URLs:     - REST API:      http://localhost:8081/api/v1
             - Swagger UI:    http://localhost:8081/swagger-ui.html
             - H2 DB Console: http://localhost:8081/h2-console

B) CUSTOMER & PUBLIC SERVICES PORTAL (Terminal 2)
   Files:    frontend/index.html (Public) & frontend/user.html (Customer)
   Command:  npm run customer
             (or .\start-customer-portal.bat)
             (or cd frontend && npx serve -l 5500)
   URL:      http://localhost:5500
   Audience: General Public & Customers only (No vendor tools visible)

C) DEDICATED VENDOR COMMAND PORTAL (Terminal 3)
   Files:    frontend/vendor.html & frontend/vendor-dashboard.html
   Command:  npm run vendor
             (or .\start-vendor-portal.bat)
             (or cd frontend && npx serve -l 5501)
   URL:      http://localhost:5501/vendor.html
   Audience: Service Providers & Vendors only (Role-protected management)

---------------------------------------------------------------
3. PERMANENT DATABASE STORAGE & CLOUD SERVERS
das---------------------------------------------------------------
- Default Storage:   Persistent disk file database at `./data/multivendordb`
                     (Zero installation needed, all users, bookings & services stored permanently!)
- Cloud DB Servers:  To connect to remote cloud servers (Neon Postgres, Supabase, Railway, Aiven):
                     Set environment variables before running:
                     $env:DB_URL="jdbc:postgresql://ep-example.neon.tech/multivendordb?sslmode=require"
                     $env:DB_USERNAME="neondb_user"
                     $env:DB_PASSWORD="neondb_password"
