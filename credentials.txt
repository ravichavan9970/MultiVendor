===============================================================
MULTI-VENDOR ENTERPRISE PLATFORM - RUN COMMANDS & ACCESS INFO
===============================================================

---------------------------------------------------------------
1. RUN FULLSTACK APPLICATION (Single Command)
---------------------------------------------------------------
cd D:\Projects\MultiVendor\backend
mvn spring-boot:run

(Alternative using Maven Wrapper):
.\mvnw spring-boot:run

Single-Port Fullstack URLs (Spring Boot serves everything):
- Dedicated User Portal:    http://localhost:8081/user.html (or http://localhost:8081)
- Dedicated Vendor Portal:  http://localhost:8081/vendor.html
- REST API Base URL:        http://localhost:8081/api/v1
- Interactive Swagger UI:   http://localhost:8081/swagger-ui.html
- Persistent DB Console:    http://localhost:8081/h2-console 
  (JDBC URL: jdbc:h2:file:./data/multivendordb | User: sa | Password: [blank])


---------------------------------------------------------------
2. OPTIONAL STANDALONE FRONTEND (Terminal 2)
---------------------------------------------------------------
cd D:\Projects\MultiVendor\frontend
npx serve -l 5500

Frontend URLs:
- Dedicated User Portal:    http://localhost:5500/user.html (or http://localhost:5500)
- Dedicated Vendor Portal:  http://localhost:5500/vendor.html

4. PERMANENT DATABASE STORAGE & CLOUD SERVERS
---------------------------------------------------------------
- Default Storage:   Persistent disk file database at `./data/multivendordb`
                     (Zero installation needed, all users, bookings & services stored permanently!)
- Cloud DB Servers:  To connect to remote cloud servers (Neon Postgres, Supabase, Railway, Aiven):
                     Set environment variables before running:
                     $env:DB_URL="jdbc:postgresql://ep-example.neon.tech/multivendordb?sslmode=require"
                     $env:DB_USERNAME="neondb_user"
                     $env:DB_PASSWORD="neondb_password"
